# Webrender Markdown Viewer — releases

Downloads for **Webrender Markdown Viewer** (called *Markdown viewer* until 1.1.0), a small desktop
program for reading Markdown files, from Nextwaveweb Ltd — for Windows, macOS and Linux. What it is,
the download links and what to expect on first run are on its page:

**https://nextwaveweb.co.uk/products/webrender-markdown-viewer**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the downloads as its assets. Every download carries a README (what you need,
install, the first-run warning, printing, removal) and a `THIRD-PARTY-NOTICES.txt` listing the
open-source components it is built from — `README.txt` beside the program in the Windows and
macOS zips, `/usr/share/doc/markdown-viewer/` once the Linux package is installed.

All three platforms are at 1.1.0. The product page links each platform's current download.
