# Markdown viewer — releases

Downloads for **Markdown viewer**, a small desktop program for reading Markdown files, from
Nextwaveweb Ltd — Windows now, macOS and Linux to follow. What it is, the download link and
what to expect on first run are on its page:

**https://nextwaveweb.co.uk/products/markdown-viewer**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the download as its asset. Every download carries a `README.txt` (what you need,
install, the first-run warning, printing, removal) and a `THIRD-PARTY-NOTICES.txt` listing the
open-source components it is built from.
