# Webrender Markdown Editor — releases

Downloads for **Webrender Markdown Editor** (called *Webrender Markdown Viewer* until 1.2.0, and *Markdown
viewer* before 1.1.0), a small desktop program for reading and editing Markdown files, from Nextwaveweb Ltd —
for Windows, macOS and Linux. What it is, the download links and what to expect on first run are on its page:

**https://nextwaveweb.co.uk/products/webrender-markdown-editor**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the downloads as its assets. Every download carries a README (what you need,
install, the first-run warning, printing, removal) and a `THIRD-PARTY-NOTICES.txt` listing the
open-source components it is built from — `README.txt` beside the program in the Windows downloads
and the macOS disk image, `/usr/share/doc/markdown-viewer/` once the Linux package is installed.

Windows is at 1.3.0, an installer and a zip, which adds *Open from Webrender…* and *Save to Webrender…*.
macOS and Linux are at 1.2.0 until their 1.3.0 follows: for macOS a disk image signed by Nextwaveweb Ltd and
notarized by Apple, for Linux a `.deb`. GitHub's *latest* release is the Windows one, so take the Mac and Linux
downloads from the v1.2.0 release or from the product page, which links each platform's current download.
